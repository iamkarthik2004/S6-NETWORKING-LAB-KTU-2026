## 📖 Overview  
Welcome to the **S6 Networking Lab Repository** 🚀  

This repository contains **well-structured lab programs** for the **Computer Networks Laboratory** prescribed under the **KTU 2019 Scheme** for **Semester 6 (CSE)**.  
It serves as a **reference guide** for understanding core networking concepts through **hands-on implementations**.

The programs are designed to help students prepare for:  
✔ Lab exams  
✔ Viva voce  
✔ Conceptual clarity in networking fundamentals
