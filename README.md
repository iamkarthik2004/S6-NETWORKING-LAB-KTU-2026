# S6-NETWORKING-LAB-KTU-2026

This repository contains the **Computer Networks Laboratory programs** for **Semester 6 (S6)** of the **B.Tech Computer Science and Engineering (CSE)** curriculum under **APJ Abdul Kalam Technological University (KTU)** for the academic year **2025–2026**.

The programs included here are implemented as part of the **Networking Lab** and follow the KTU syllabus guidelines.

## 📘 Course Details

- **Course Name:** Computer Networks Laboratory  
- **Semester:** S6  
- **Branch:** Computer Science and Engineering (CSE)  
- **University:** APJ Abdul Kalam Technological University (KTU)  
- **Academic Year:** 2025–2026  

---

## 🧪 List of Experiments

The repository includes implementations of the following networking concepts and experiments:

1. Socket programming – TCP client-server communication  
2. Socket programming – UDP client-server communication  
3. Simulation of **Stop-and-Wait Protocol**  
4. Simulation of **Go-Back-N Protocol**  
5. Simulation of **Selective Repeat Protocol**  
6. Error detection techniques (CRC, Checksum, etc.)  
7. Distance Vector Routing Algorithm  
8. Link State Routing Algorithm  
9. Congestion control concepts  
10. Any additional experiments as prescribed by KTU

> ⚠️ Exact experiments may vary slightly depending on college/internal lab requirements.
